# Fontes

Subconjunto latino (variável) de duas famílias do Google Fonts, incluídas no jogo para ele funcionar sem internet:

- `baloo2-latin.woff2`: Baloo 2, de Ek Type
- `nunito-latin.woff2`: Nunito, de Vernon Adams e colaboradores

As duas são distribuídas sob a SIL Open Font License 1.1 (https://openfontlicense.org), que permite uso e redistribuição, inclusive em produtos comerciais.
